# Supply Network Planning (SNP) Heuristic Engine

Модуль распределения ограниченного товарного запаса между конкурирующими заявками в условиях дефицита.

Решает элементарную операцию планирования цепи поставок: доступный объём одной позиции в одном периоде делится между несколькими заявками с разными приоритетами и транспортными ограничениями.

#### Основные гипотезы
* **Справедливое распределение**: пропорциональное деление дефицита между заявками одного приоритета (метод наибольших остатков).
* **Соблюдение лимитов**: применение ограничений по минимальным партиям (`min_lot`) и кратностям отгрузки (`rounding_value`).
* **Приоритет как жёсткий порядок**: заявки старшего приоритета не уступают объём младшим (лексикографические тиры).
* **Защита от перепоставки**: по умолчанию отгрузка не превышает запрошенный `demand_qty` (округление вниз); флаг `--allow-overship` включает дотяжку до следующего лота.

#### Логика алгоритма (Three-Pass Apportionment)

Ядро не использует тяжёлых сторонних библиотек (только стандартная библиотека Python) и работает в три прохода внутри каждого тира приоритета:

1. **Базовые доли**: каждой выполнимой заявке гарантируется её `min_lot`.
2. **Пропорциональный добор**: остаток делится пропорционально недополученному спросу, доли округляются вниз до транспортной кратности.
3. **Дораздача остатков**: нераспределённый из-за округлений сток передаётся целыми лотами тем заявкам, которые могут принять ещё один лот.

Ничьи между равноприоритетными заявками разрешаются детерминированно по `request_id` — повторный запуск даёт идентичный план. Противоречивые записи (отрицательные `min_lot` / `rounding_value`) не обрушивают расчёт: они изолируются и выводятся отдельным блоком.

#### Установка и запуск

Сторонних зависимостей нет, поэтому виртуальное окружение не обязательно.

Для Mac / Linux:

```bash
python3 -m snp_heuristic
```

Для Windows (PowerShell):

```powershell
python -m snp_heuristic
```

Параметры CLI: `--supply <path>` (по умолчанию `data/supply.csv`), `--requests <path>` (по умолчанию `data/requests.csv`), `--allow-overship`.

Тесты:

```bash
python -m pytest -q
```

#### Структура проекта

* `snp_heuristic/allocation.py` — ядро алгоритма (жадная эвристика по тирам).
* `snp_heuristic/engine.py` — оркестрация по всем `case_id`.
* `snp_heuristic/io.py` — чтение CSV и форматирование результата.
* `snp_heuristic/validation.py` — нормализация и изоляция противоречивых записей.
* `snp_heuristic/domain.py` — доменные модели (frozen dataclasses).
* `snp_heuristic/cli.py` / `snp_heuristic/__main__.py` — точка входа `python -m snp_heuristic`.
* `data/` — исходные данные (`supply.csv`, `requests.csv`).
* `tests/` — pytest-тесты гипотез (min_lot, перепоставка, детерминированность, I/O).
* `REPORT.md` — отчёт и обоснование решений.
